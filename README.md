# FIRST Materials Runtime · B8-04

Учебно-практическое задание B8-04 R3: подготовка утверждённых материалов FIRST.

**Статус: промежуточная работа, реализация не завершена, приёмка не заявлена.**

## Что делает компонент

Компонент должен проверять запрос и права пользователя, учитывать остановку автоматизации и передачу человеку, получать утверждённый каталог и материал через доверенные зависимости, сохранять материал и подготавливать действие для последующей отправки. Сам компонент не выполняет реальные отправки.

Публичная точка входа: `create_service(ports).execute(operation, request)`.

Операции: `prepare` и `prepare_initial`. Точные требования и границы зависимостей находятся в исходном пакете.

## Что есть в опубликованном коде

- Строгая проверка полей запроса и scope.
- Проверка идентификаторов и канонического UUID кампании.
- Проверка аутентификации, capability и принадлежности клиенту.
- Работа через переданный контекст транзакции.
- Блокировка автоматизации при STOPPED / HUMAN / HANDED_OFF.
- Проверка ответа каталога, версии и признака утверждения.
- Проверка идентичности события, полноты покрытия и типа HUMAN_QUESTION.
- Вызов `f129.materialize`.

Успешные ветки заканчиваются `NotImplementedError`: сохранение, dispatch и initial-цепочка в этом снимке не реализованы. Не используйте его для реальных отправок или подключения рабочей БД.
