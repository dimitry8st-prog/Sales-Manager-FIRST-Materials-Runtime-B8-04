# B8-04 R5 — текущий возврат исполнителя

Это актуальный возврат. R3 и R4 — предыдущие архивы, их результаты ниже отдельно и не заменяют R5.

R5 добавляет два реальных конкурентных сценария worker/STOP и упаковывает архив путями ZIP через `/`.

## Фактический итог R5

Проверки выполнены дважды, оба раза с кодом выхода 0.

- Собственные тесты без DSN: 59 обнаружено, 50 выполнено, 9 пропущено.
- CP0: PASS, защищённые файлы без расхождений.
- CP1: 19/19 PASS.
- CP2: 9/9 PostgreSQL-тестов, включая crash до и после commit, изоляцию scope, SQL-ограничение и оба конкурентных STOP-сценария.
- PG_GATE `before_restart` и `after_restart`: PASS на том же контейнере `b8-04-r5-cp2`. Между фазами был `docker restart`, повторного seed не было.
- Патч применяется к чистой выданной базе и побайтно совпадает с семью файлами возврата. Тесты и CP1 из этой копии прошли.
- CP3: NOT_RUN. Это этап интегратора.
- CP4: NOT_RUN. Это этап независимого аудитора.

Это возврат исполнителя, не приёмка всей системы FIRST. Реальных отправок и рабочей базы не было.
