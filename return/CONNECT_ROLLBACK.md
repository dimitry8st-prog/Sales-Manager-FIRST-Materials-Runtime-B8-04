# Подключение и откат

1. Работать в отдельной копии исходного B8-04_R3.zip. Сверить его SHA-256 с evidence/protected_files.json.
2. До наложения solution/ и tests/ сохранить резервную копию собственных файлов. Не перезаписывать контракты, стенды, fixtures и reference_source.
3. Скопировать solution/ и tests/ этого возврата в корень копии пакета. Патч является альтернативой копированию; не применять оба способа повторно.
4. Для собственных тестов задать PYTHONUTF8=1 и PYTHONPATH=solution; запустить Python 3.12 -B -m unittest discover -s tests/first_materials_runtime -p "test_*.py" -v.
5. Из того же корня запустить Python 3.12 -B ACCEPTANCE_RUNNER.py cp0, затем cp1 --module first_materials_runtime.api.
6. CP2 выполнять только после подготовки acceptance_pg и отдельно выделенного одноразового PostgreSQL. Отсутствие DSN не считать PASS. CP3/CP4 передаются соответствующим владельцам по выданному руководству.

Откат офлайн-копии: восстановить сохранённые собственные solution/ и tests/ либо удалить только добавленные этим возвратом собственные файлы. SQL, миграции и установка общего runtime здесь не выполнялись. Процедуру производственного backup/restore и rollback/reinstall определяет и проверяет интегратор; этот документ её не заменяет.
