## Задача

1. После проверки материала и допустимости его фактов вызвать materials.save с точными полями scope, request_id, material.
2. Передавать исходный descriptor без изменения значений и порядка approved_fact_ids.
3. Ответ должен содержать только material_ref; проверить формат ID и совпадение с descriptor.
4. При неправильном ответе обеспечить откат транзакции через исключение, покидающее контекст. Снаружи преобразовать в INVALID.
5. Если изменения уже внесены, не дублировать их.

## Тесты

Через реальный service.execute проверить:
- неверный ответ materials.save;
- несовпадение material_ref;
- отсутствующую зависимость;
- точный запрос к materials.save;
- отсутствие dispatch при отказе;
- реальный откат состояния тестовой транзакции: одного Mock недостаточно.
